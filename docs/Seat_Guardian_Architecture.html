Seat Guardian: system architecture and roles

A smart library seat monitor. The MCXC444 senses the seat and gives local feedback in real time; the ESP32 links it to an LLM, a Telegram assistant and a Firebase log. Each box in the diagram is coloured by the role that owns it.
